# Imago Dei Conf 2026

Веб-приложение регистрации на конференцию.

## Стек

Next.js + TypeScript + Tailwind · деплой на Vercel

## Сейчас (MVP)

1. Welcome
2. Регистрация (контакты + обед)
3. QR-пропуск

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000
